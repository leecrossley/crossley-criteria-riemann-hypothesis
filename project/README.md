# Arithmetic criteria

This directory holds Lee Crossley's classical route to RH, Steps 0 to 9, as a source tree that imports nothing outside Mathlib.

**It does not prove RH on its own.** The proof of RH joins its Landau theorem to the theta-lift window in [`theta-window/`](../theta-window/). Its endpoints are the six Crossley Criteria of [the paper](../paper/crossley-criteria-riemann-hypothesis.md), the window, square-block, fourth-power, shell, far-pair and first-moment criteria, which reduce RH to an inequality that has no direct proof.

## Sources

[`SHA256SUMS`](SHA256SUMS) lists the SHA-256 of every source file.

- The project core is the published core of the route, with a patch of 956 diff lines in twenty-one files that replaces its imports of the reference archive.
- The compatibility layer states the classical inputs in the form the core expects, and the audit module checks the twenty-six headline theorems.
- The analysis modules are the project's two Mathlib-only developments, restricted to the 49 modules the core, dyadic reconstruction and `Crossley.WindowCriterion` use. Eight modules of the standalone window development are left out because they duplicate declarations of the core.
- The partial results are twenty-five of the project's Mathlib-only modules. Eighteen are copied unchanged, and `TentDigamma` and `TentMassIdentity` were written for this tree. `RampWindowEquivalence` imports `Reflection` in place of `Crossley.Reflection`, `AnchorWeight` imports `Mathlib` in place of `SparsePrimeGrid`, and `AnchorIdentity` adds the import `IndependentLandau.Ramp`. `TentWindow` and `TentMean` import `PrimeWindow` in place of `Crossley.WindowCriterion`, so their statements name `ThetaTransfer.primePowerDeficit` and their proofs use the matching `ThetaTransfer` lemmas.

## Build

Lean 4.33.1 and Mathlib at `0df444a360eaa60ab8c11dca51a86af692955474`.

```sh
LEAN_BIN=/path/to/toolchain/bin MATHLIB=/path/to/built/mathlib4 python3 tools/build.py
```

The script compiles every module at trust level zero in dependency order and replays each one in the kernel checker. It refuses to run if any module imports something outside this tree and Mathlib. Objects go to `.build`, which is not committed.

[`lakefile.toml`](lakefile.toml) and [`lake-manifest.json`](lake-manifest.json) are provided for `lake exe cache get && lake build`. ## Limitations

- The proof of the arithmetic inequality. With it, this project would prove `RiemannHypothesis` without the theta-lift window.
- The later research modules outside Steps 0 to 9, apart from the twenty-five partial results above. They still build against the reference archive.
- Bebel's zero-free theorem as an imported theorem, by decision. No module of the chain needs it, and the results above exponent 4 that use it keep it as two explicit hypotheses in their statements.
